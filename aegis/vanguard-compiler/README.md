## **📜 THE MISSION**

The **Vanguard Compiler** is a distributed repository of narrative audits designed to protect the "First Intent" of our cultural archives. In a world of "Mass Psychosis" and systemic redaction, this tool allows sovereign individuals to bypass the noise and reconnect with the signal.

## **🛠️ THE TOOLS**

### **1\. Vanguard Compiler Pro (Web App)**

The flagship interface. A single-page application (vanguard-compiler-pro.html) that connects directly to the **Garnet Bridge** cloud function.

* **Feature:** Upload any CSV viewing list.  
* **Feature:** Select an auditor persona (Baymax, Kenobi, Dreamer, TARS, etc.).  
* **Feature:** Watch as the AI "watches" the show with you, generating a unique thematic audit for every episode.  
* **Output:** Downloads a formatted Markdown (.md) file ready for archiving.

### **2\. The Python Core**

Located in /scripts, the\_vanguard\_compiler.py is the offline logic engine. It is useful for batch-processing large datasets locally without hitting API limits.

### **3\. The Audit Library**

Located in /audits, this folder contains the "Unbreakable Records" generated by the system.

* **The Crisis Audit:** A tactical briefing for the Earth-X crossover.  
* **The Greendale Audit:** A meta-analysis of *Community*.  
* **The Serenity Audit:** A Browncoat protocol for *Firefly*.

## **📂 REPOSITORY STRUCTURE**

* **vanguard-compiler-pro.html**: The main executable web node.  
* **index.html**: The central hub/landing page.  
* **/data**: Raw CSV fuel (Arrowverse, Star Trek, etc.).  
* **/audits**: Compiled Markdown records.  
* **/scripts**: Python logic for local operations.
