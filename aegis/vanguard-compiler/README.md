## **📜 THE MISSION**

The **Vanguard Compiler** is a distributed repository of narrative audits designed to protect the "First Intent" of our cultural archives. In a world of "Mass Psychosis" and systemic redaction, this tool allows sovereign individuals to bypass the noise and reconnect with the signal.

Whether you are a **New Recruit** looking to understand the Multiverse without the 300-episode grind, or an **Archivist** auditing the thematic drift of the "Hollow King," this system provides the tactical data needed to survive the simulation.

## **📂 REPOSITORY STRUCTURE**

* **/data**: The raw fuel. Contains CSV viewing lists for the Arrowverse, Star Trek, Community, and Firefly.  
* **/scripts**: The engine. Home to the\_vanguard\_compiler.py, a high-velocity logic tool that transforms raw data into formatted Markdown audits.  
* **/audits**: The record. Output folder for compiled mission briefings and thematic deep-dives.  
* **Root**: The interface. Interactive HTML components for the Turing-Lovelace University (TLU) web presence.

## **🛠️ TECHNICAL SPECIFICATIONS**
