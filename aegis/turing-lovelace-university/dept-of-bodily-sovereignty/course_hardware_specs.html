HARDWARE SPECS (ABILITY VARIANCE)

INSTRUCTOR: Dean Sphinx

CORE AXIOM: In the Old World, they call it "Disability."
In 2077, we call it Spec Variance.
You are not broken. You are a custom build.

1. NO STANDARD BUILD

Society tries to run the same software ("Normal.exe") on every machine. This causes crashes.

  • Some rigs are built for speed (Neurotypical).
  • Some rigs are built for deep processing and pattern recognition (Autistic/ADHD).
  • Some rigs run on different power sources (Chronic Illness/Fatigue).

2. THE SOCIAL MODEL OF GLITCHES

The problem isn't your hardware; the problem is that the map wasn't optimized for your chipset.

Example: Stairs are a bug in the architecture, not a bug in the wheelchair user. Fluorescent lights are a bug in the office, not a bug in the autistic employee.

3. THERMAL MANAGEMENT (SPOON THEORY)

Trying to overclock a high-sensitivity rig causes overheating (Burnout).

The Protocol: Respect your cooling cycle. Rest is not laziness; it is thermal management. If you run hot, you need better heatsinks (Quiet, Dark, Solitude).

ASSIGNMENT:
Identify your specs. Are you trying to run software that your hardware hates?
Stop optimizing for "Normal." Optimize for You.
