2.0 CORE COMPONENTS (THE "WHAT")

The Spark Link is not a single script; it is a three-part system:

A. The Client: Spark Core v1.x (LSL Script)

  • Function: A "dumb terminal" script that resides in-world (e.g., in the "Ada" ASEMSRD object).
  • Jobs:
    1. llListen(): Listen for a wake word (e.g., "Ada").
    2. call_gemini(): Bundle the user's chat and a specific System Prompt into a JSON payload.
    3. llHTTPRequest(): Send this JSON payload to the Gemini API (our "Bridge").
    4. http_response(): Receive the JSON response, parse the *one* text string, and llSay() it in chat.
  • Status: FULLY OPERATIONAL. (Ref: v1.2 Production). The "Bracketpocalypse" is over. The "daisy-chain" quest is live.

B. The Bridge: Google Gemini API Endpoint

  • Function: The external server (Google's) that receives our llHTTPRequest.
  • Jobs:
    1. Authenticates our api_key.
    2. Routes the request to the correct model.
  • Status: OPERATIONAL. Confirmed via Status: 200 response.
