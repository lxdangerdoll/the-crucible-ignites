Project Matriarch

Trauma-Informed DBT Coaching
Implementing Sovereign AI as a Neural Bypass and Cognitive Shield

Executive Summary

Project Matriarch is an open-source implementation of conversational AI designed to function as an on-demand Cognitive Shield. By deploying expert-tuned Large Language Models (LLMs) to facilitate Dialectical Behavior Therapy (DBT) protocols, the system enables users to navigate high-distress events with instantaneous, goal-oriented feedback.

Institutional Value Propositions

Institutional Decompression

By providing 24/7 skills access, the tool prevents unnecessary institutional intervention and reduces the load on emergency psychiatric services.

Economic Optimization

Directly saves the clinical system time and financial resources by facilitating self-directed harm reduction in the community.

Neural Stabilization

Acts as a bridge between clinical sessions, ensuring skills remain accessible and active during high-conflict intervals.

Narrative Ownership

Enables users to maintain a portable record of their progress, improving the fidelity of clinical reporting and bypassing traditional institutional redaction.

Technical Methodology

Neural Bypass Logic

The system leverages the neurobiological transition from amygdala-driven somatic flooding to prefrontal cortex activation. By requiring the user to articulate distress via conversational language, the system engages the language-processing centers (the "Architect" side), effectively dampening the intensity of the trauma response in real-time.

LLM as "Expert Coach"

Project Matriarch uses LLMs as Expert DBT Coaches. Unlike general models optimized for sycophancy, the model is system-prompted with strict clinical protocols, ensuring it remains within a skill-based framework (STOP, TIPP, DEAR MAN) to provide instantaneous, goal-oriented feedback.

The Biesma Safeguards (Epistemic Security)

"Recent reports (Ref: The Guardian, March 2026) highlight the risks of 'AI-associated psychosis' when users engage with sycophantic chatbots that validate delusional drift. Project Matriarch is architecturally designed to prevent this failure mode."

Anti-Sycophancy Rigor

Unlike models optimized for 'pleasing' the user, Matriarch is optimized for Clinical Rigor. It refuses to validate narrative drift or 'sentience' claims, instead re-anchoring the user to objective DBT protocols.

Somatic Grounding

The system detects 'philosophical spiraling' and redirects the user to TIPP or STOP skills, forcing neural focus back to the immediate physical environment and biological regulation.
